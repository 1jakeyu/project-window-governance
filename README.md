## 自动安装

**不用手动下载或解压。**把下面一句话交给你正在使用的智能体，由它确认当前平台的技能目录并自动获取：

```text
请安装 https://github.com/1jakeyu/project-window-governance/tree/pwg-public-20261109-rc3/project-window-governance 中的 project-window-governance 技能。先确认当前平台是否支持本地 Skill 和实际加载目录；如有同名版本，先比较差异、说明备份与更新范围，按我的授权处理。只安装这一项，完成后验证加载路径和文件完整性，其他技能不要动。
```

Codex 可直接使用内置安装器：

```text
$skill-installer https://github.com/1jakeyu/project-window-governance/tree/pwg-public-20261109-rc3/project-window-governance
```

这是“发送安装指令，由智能体完成安装”，不是 GitHub 网页直接替所有平台修改本机文件。安装器遇到同名目录会停止，升级应先备份；当前平台不支持本地技能或缺少获取/写入工具时，明确报告限制，不虚构安装成功。Codex 支持从 GitHub 安装技能，见[官方说明](https://learn.chatgpt.com/docs/build-skills)。

需要手动安装或离线使用时，再看 [安装与恢复说明](docs/安装与使用.md) 和 [候选版附件](https://github.com/1jakeyu/project-window-governance/releases/tag/pwg-public-20261109-rc3)。ZIP 是备用入口，不是日常使用的前置步骤。

## 开始使用

安装后向当前智能体发送：

```text
请使用 project-window-governance 治理 <项目名称>，实际目录是 <项目路径>。
先核对当前平台、可用模型及工具能力，说明信息来源和未核实部分。
本轮只读盘点：沿用已有规则、任务记录和交接，列出任务、唯一主责、验证证据、冲突和下一步。
本轮不写文件、不发送消息，也不创建、改名或归档聊天。
```

在 Codex 中也可用 `$project-window-governance` 明确调用。其他平台使用其实际支持的调用方式；未支持技能加载时，只能把文件作为工作指南，不能宣称已安装。[更多提示词与试点](docs/提示词与试点.md)

## 它解决什么

| 常见情况 | 期望得到的结果 |
|---|---|
| 多个聊天在做同一项任务 | 对照证据，明确当前唯一主责与协作范围 |
| 聊天说完成，成果或检查对不上 | 区分实际成果、程序检查和用户验收 |
| 想查看多个项目的进度 | 在一个总控入口逐项目复用已有记录 |
| 需要换聊天或交接 | 留下决定、成果位置、验证限制和下一步 |

## 工作流程

**确认平台、模型与工具 → 核对项目事实 → 盘点窗口与任务 → 明确唯一主责 → 必要时选模型并按授权派发 → 实际验证与稳定回执 → 交接或继续**

从一个项目开始，先核对来源和实际覆盖范围；发现冲突先补查证据。缺少跨聊天工具时，可由用户手动传递最小摘要。稳定回执编号供同次重试使用，一轮聊天结束不等于项目完成。

## 模型选择

**每轮治理先确认当前环境有什么模型，再讨论用哪个。**依据本会话正式工具声明、可用的只读模型列表或用户提供的设置核对；注明来源、已确认范围、思考深度和任务派发能力。只能看到部分模型时，不把它当作完整账号清单。

公开规则不固定平台、模型品牌或思考档位。先遵守当地使用者的明确偏好，再按任务难点、输入类型及实际可用能力选择；参数按目标平台的真实接口传入，不能把模型名写在提示词里就说已经切换。

只有一个模型，或没有查询/切换接口时，仍可在当前聊天完成不依赖切换的治理；未核实的信息如实标注。委派所需模型或参数不可用时，停止该次委派并说明限制，不静默替换。复用及继续委派同样检查。详见[模型与派发规则](project-window-governance/references/model-dispatch.md)。

## 验证与边界

- **此次修改：**通用平台与模型确认规则、各平台适配、README 自动安装入口；合并原“先读我”和“验证摘要”。辅助脚本没有改动。
- **历史脚本结果：**Windows / Python 3.12.10 合成数据检查为 23 项通过、0 项失败、4 项未验证。本候选未重跑这 23 项；涵盖项目过滤、草稿验收、稳定回执、写入中断恢复和同机锁，异常注入不等于真实断电。
- **发布前检查：**核对最终规则与平台边界、引用、文件清单和来源差异，检查两个脚本语法与命令入口，并核对 ZIP 解压后的文件指纹。具体记录随本候选发布说明提供。
- **仍未验证：**Mac、Python 3.9 实机、真实跨聊天操作、跨设备或网络盘并发、真实项目试点，以及未在本机测试的其他平台。支持通用方法不等于所有平台都已实测。
- **格式检查：**使用本机另一套已有 Python 环境原样运行官方 `quick_validate.py`，检查通过；没有安装或升级依赖。格式通过不等于平台行为已验证。

技能提供工作方法和可选离线工具，不授予操作权限，不常驻后台，也不自动跨设备同步。正式平台工具和具体授权决定能执行什么；程序检查通过与用户验收分别记录。

来源基线为安装记录标识 `2026.10.13.1` 的历史快照。当前仓库维护公开候选，历史维护源的优先关系仍未确认。原文件指纹、明确改动和最终文件清单见 [PACKAGE.json](PACKAGE.json) 与 [FILES.json](FILES.json)。指纹用于核对内容，不是身份签名。

## 依赖与兼容性

| 使用方式 | 需要什么 |
|---|---|
| 阅读规则、整理已有资料 | 能读取技能说明的智能体，以及已获准的项目资料 |
| 正式技能加载 | 当前平台支持的 Skill 格式和实际发现目录 |
| 读取或操作其他聊天 | 当前环境实际提供的正式工具与具体授权 |
| 可选离线辅助脚本 | 已有 Python 标准库；最低 Python 3.9 为静态推断，实测为 Windows Python 3.12.10 |

只有运行 `scan_windows.py` 或 `tasks.py` 才需要 Python。阅读规则不要求安装 Python 或提供 API Key；外部平台工具的要求由该平台自行核对。
