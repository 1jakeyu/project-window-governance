## 快速开始

先到[版本下载页](https://github.com/1jakeyu/project-window-governance/releases/tag/pwg-public-20261109-rc2)领取 `pwg-public-20261109-rc2.zip` 和 `SHA256SUMS.txt`，按[安装说明](docs/安装与使用.md)确认目标目录。

安装技能后，在选定项目的聊天中输入：

```text
$project-window-governance
请先只读盘点 <项目名称>，实际目录是 <项目路径>。
沿用已有规则、任务记录和交接资料；未知的入口请标明。
列出任务、当前唯一主责、验证证据、冲突和下一步。
本轮不写文件、不发送消息，也不创建、改名或归档聊天。
```

将尖括号里的内容换成实际信息。[安装与使用](docs/安装与使用.md) · [更多提示词与试点](docs/提示词与试点.md)

## 它解决什么

| 常见情况 | 期望得到的结果 |
|---|---|
| 多个聊天在做同一项任务 | 对照证据，明确当前唯一主责与协作范围 |
| 聊天说完成，成果或检查对不上 | 区分实际成果、验证结果和用户验收 |
| 想查看多个项目的进度 | 可选一个总控入口，逐项目沿用已有记录 |
| 需要换聊天或交接 | 留下决定、成果位置、验证限制和下一步 |

## 工作流程

**只读盘点 → 明确唯一主责 → 按任务选模型 → 授权内派发 → 真实验证与稳定回执 → 最小交接**

从一个项目开始，先核对事实来源和实际覆盖范围；发生冲突时先查证。需要派发时，核对目标环境的工具和权限；完成后按真实结果记录通过、失败或未验证。稳定回执编号用于同次重试，不把一轮结束当成项目完成。

## 模型派发

**已确认偏好示例 / 在目标环境确认后采用：**

| 任务类型 | 请求模型 | 思考深度 |
|---|---|---|
| 常规开发与测试、Skill 维护、资料综合 | `gpt-6.1-sol` | `ultra` |
| 文案图文、截图版式、界面操作 | `gpt-6.1-terra` | `ultra` |
| 复杂故障、重要架构、矛盾证据与复杂取舍 | `gpt-6-astra` | `ultra` |

先判断是否需要派发；工具调用必须实际传入模型和深度。当前 `spawn_agent` 覆盖模型时使用 `fork_turns: none`。模型或深度不可用时停止该次委派，不静默降级；子智能体继续派发也遵守同一规则。新设备先确认模型、工具支持和用户偏好；这些示例不是所有用户的通用默认值。

## 验证与边界

此前在 **Windows / Python 3.12.10** 上对离线脚本进行合成数据验证：**23 项通过、0 项失败、4 项未验证**；本次仅调整技能指引与说明，两个脚本保持不变，未重新运行这 23 项测试。最低 Python 3.9 是静态推断，Python 3.9 与 Mac 实机尚未验证。详见 [验证摘要](验证摘要.md)。

Skill 提供工作方法和可选离线工具，本身不授予聊天权限，也不会后台常驻或自动跨设备同步。跨聊天操作依赖当前环境的正式工具和具体授权；没有工具时可由用户手动传递最小摘要。

本候选基于安装记录标识为 `2026.10.13.1` 的历史快照：保留 11 个原技能文件，修改技能入口并新增模型派发引用。历史正式维护源仍未确认；本独立仓库维护公开候选，不据此替换其他历史来源或本机现用安装。来源及差异见 [PACKAGE.json](PACKAGE.json)，逐文件指纹见 [FILES.json](FILES.json)。

## 安装要点

1. 将版本 ZIP 解压到新文件夹，先看中文安装说明。
2. 让目标 Codex 确认它实际读取的技能目录，再复制整个 `project-window-governance` 文件夹。
3. 安装后应直接得到 `<已确认的技能目录>/project-window-governance/SKILL.md`，不要嵌套两层同名文件夹。
4. 遇到已有同名技能，先比较文件并提出备份与替换计划；获批后再替换，不合并覆盖。
5. 用上面的只读提示词确认实际加载路径。路径不对、重复加载或无法发现时，先停止安装变更并保留现状。

本仓库根包含交付说明，真正需要复制的技能在子目录 `project-window-governance/`。安装不会把旧设备的批准转移到新设备。

## 依赖与兼容性

| 使用方式 | 需要什么 | 本候选验证情况 |
|---|---|---|
| 阅读技能、整理已有资料 | 能加载技能的目标 Codex；已获准的项目资料 | 已进行合成请求演练；目标设备发现待验证 |
| 读取或操作其他聊天 | 目标环境提供的正式列表、读取和相应操作工具 | 实际能力按当前环境核对；没有工具可手动传递摘要 |
| 两个离线辅助脚本 | Python 标准库；最低 Python 3.9 为静态推断 | Windows Python 3.12.10 实测；Python 3.9 实机未验证 |
| Mac 上运行辅助脚本 | 目标设备已有合适 Python | 已做静态检查；Mac 实机及锁并发未验证 |

只有运行 `scan_windows.py`、`tasks.py` 才需要 Python。阅读与使用技能说明不要求安装 Python，也不要求 API Key。
