# 每轮模型确认与派发

每轮治理先确认当前环境能使用什么，再决定是否需要选模或派发。这套规则适用于任何智能体平台，不设固定品牌、模型清单或思考深度，不修改全局运行配置。平台字段和条件示例只在相应适配中说明。

## 1. 确认本轮环境与证据范围

先查看本会话已经提供的真实声明和现行规则，只补查会影响本轮工作的缺口：

| 要确认什么 | 可接受的证据与边界 |
|---|---|
| 实际平台与已知当前模型 | 宿主明确提供的信息或用户提供的当前设置；注明来源。未提供就写未知或未核实，不能由助手自述、品牌或工具名称推定。 |
| 可用模型及范围 | 优先本会话真实工具声明、平台官方只读模型列表接口或用户已提供的设置；区分当前聊天、临时 Agent、目标聊天、执行器和接口账号各自的范围。 |
| 深度、多模态与选择能力 | 根据本轮任务核对需要的思考深度、图片等输入能力，以及能否在当前聊天或派发时选择配置；只确认有证据支持的能力，不按模型名字推定。 |
| 用户与项目现行偏好 | 读取已经提供或已知入口中的有效规则，核对本轮最新具体决定；按实际生效的层级处理，不把技能示例或源设备偏好当作当地默认。 |

确认不等于必须调用额外接口：本轮已有的有效声明和设置可以复用；旧回执中的模型清单只作线索，不能直接证明本轮可用性。简要说明来源、已核实范围和必要的未知项即可，不新增模型台账、不要求列出整个账户。接口列出了模型，也不一定证明当前目标有调用权限或支持任务所需能力。

只使用当前环境已提供且获准的只读渠道，不读取密钥或其他凭证，不遍历用户配置、无关项目或完整历史，也不为查询模型安装依赖或修改设置。环境没有查询能力时标记“可用模型未核实”；单模型平台如有可信证据，只记录该范围。两种情况都可以继续当前聊天里不依赖选模的治理，不强制切模型或编造候选清单。

## 2. 需要选择或派发时再判断

- 先判断执行方式：适合当前聊天的工作就在当前聊天完成；可以独立交付和验收的工作可用临时子智能体。复杂任务不等于每项都委派，不为选模型额外拆任务。用户需要长期跟进的独立聊天，仍须明确建窗授权。
- 依据任务的主要难点、用户明确偏好和已证实的能力选择配置，不因主聊天使用某模型就一律继承。小界面改动若主要风险在数据迁移，应按迁移难点判断；不要只按“按钮”“截图”等表面词归类。
- 没有模型偏好时，在已核实的可选范围内按任务所需能力选择；单模型且能力适合时可以直接使用。能力不明时说明不确定性，不虚构性能排名、官方推荐或费用优势，也不把“不知道”说成“不可用”。
- 派发前用一句话交代执行方式、选择及理由，并指明必要的来源和范围。要求的能力或配置尚未核实时先做最小补查；无法满足时按下一节停止该次委派，继续不依赖它的已授权工作。

## 3. 按平台自己的契约设置与复用

1. 读取当前委派工具的真实接口与限制，确认它能表达现行规则要求的模型、深度及其他必要配置，并实际通过该平台支持的方式设置。只在提示词中写模型名或深度，不算选择了运行配置；不把某个平台的字段套到其他平台。
2. 不继承完整历史时，提供任务目标、准确资料入口、允许范围、验收标准、现行偏好和继续委派约束。子智能体继续委派时同样先检查任务与配置，不能因嵌套层级而跳过。
3. 复用已有子智能体前，核实它的可信模型与深度配置是否适合新任务。跟进工具不能改配置时，不声称通过新提示词切换成功；缺少可信配置也不能假定符合偏好。确需另一配置时，在已授权范围内选择能满足要求的方式，并避免重复派工和重复写入。
4. 要求的模型、深度、能力或必要参数不可用、无法核实，或不能按要求设置时，停止该次委派，说明具体限制；不静默换模型、降低深度或改全局配置绕过。与该次委派无关且已授权的工作继续。采用例外配置须有当地用户对该例外的明确决定。

未附专用适配的平台也按以上过程工作：以本会话真实接口为准；没有模型查询或委派能力时，标注范围并继续当前聊天可完成的部分，不猜接口、不要求迁移到特定平台。平台适配是补充说明，不是支持白名单。

## 4. 授权与记录

模型和深度已经选好，不代表获得其他操作授权。只有用户明确要求时才创建用户可见的新聊天，只有明确授权向目标聊天发消息时才发送。未授权时保留可审查派发草稿，不自动建窗、广播或发消息，也不批量切换已有聊天的模型。

在项目已有任务记录或回执的文字字段中，简记配置来源与范围、请求模型和深度、理由及派发结果；没有派发就如实记录当前聊天处理，无需为此变更回执格式。请求值、工具接受调用与实际运行模型是不同证据；有可靠平台运行证据才能记为实际模型，否则写“已请求，实际模型未核实”。子智能体自述不作为运行配置证明。

用户全局入口与项目特有规则继续各司其职，不把某位使用者的模型表发布成所有平台的默认规则。其他设备须由其用户在明确授权范围内采用当地入口与偏好，不继承源设备路径或操作批准；不能从一处写入推导所有聊天已重载、项目已读取或设备已同步，需要分别核验。
